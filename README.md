# BrandSim — UI-система: образец для разбора

BrandSim — обучающая бизнес-симуляция по маркетинговой стратегии: участник
пять игровых лет управляет тремя брендами на вымышленном рынке
холодильников. Здесь **нет самой игры**. Здесь только то, на чём держится
её интерфейс: описание продукта, дизайн-система, UI-кит с правилами
описания компонентов, машинная проверка и правила работы для
ИИ-агента.

Это разовый снимок настоящего проекта, а не шаблон. Можно разобрать, как
файлы связаны между собой, и собрать такую же систему для своего продукта.

## Открыть кит

Нужен только Python 3.

```bash
cd kit
python3 -m http.server 8000
```

На Windows вместо `python3` — `py`. Откройте <http://localhost:8000/kit.html>. Слева — основа (цвета, шрифты,
отступы, иконки), справа — компоненты: у каждого карточка с матрицей
«значения опций × состояния».

Проверка дизайн-системы:

```bash
bash kit/design-gate.sh
```

## Что читать и в каком порядке

| # | Файл | Что это |
|---|---|---|
| 1 | `GUIDE.md` | как система устроена: что несущее, что поддерживающее |
| 2 | `PRODUCT.md` | продукт: пользователи, назначение, термины |
| 3 | `DESIGN.md` | дизайн-система: токены, шрифты, цвета, компоненты |
| 4 | `KIT-RULES.md` | ядро: как описывать компонент, чтобы кит оставался словарём |
| 5 | `KIT-BINDING.md` | как ядро выполнено именно здесь + аудит долгов |
| 6 | `UI-KIT.md` | спека страницы кита и архитектура токенов |
| 7 | `CLAUDE.md` | правила работы агента над интерфейсом |
| 8 | `REPLICATE.md` | план: повторить у себя |

Экраны игры в репозиторий не входят. Где документы говорят про «экран
рынка» или «экран решений» — это экраны исходного продукта; видно здесь
только то, что рисует страница кита.

## С агентом

Откройте папку в Claude Code (или другом агенте — правила продублированы
в `AGENTS.md`) и скажите: «объясни, как здесь всё устроено» или «помоги
повторить это для моего продукта». В начале `CLAUDE.md` агент найдёт, что
делать при первом запуске.
